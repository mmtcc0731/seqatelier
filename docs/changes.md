# 開発版 0.3.0 の変更

- 基本構成を各端末での実行＋ユーザーの同期フォルダへ整理。専用サーバーは任意。
- `workspace use PATH` / `workspace show` を追加。端末固有のパスとworkspace IDを登録。
- パスが消えた場合や別データに置き換わった場合に、自動的な空workspace作成を防止。
- 完成したSQLiteカタログを原子的に置換する保存方式へ変更。同一端末の書き込みはロックで調整。
- 同期途中の配列不足、検出可能な競合コピー、保存中に到着した外部変更を報告。
- schema 2へ固有IDを追加。旧開発版のデータはバックアップ後に明示的な `init` で更新。
- Windows/Linuxでのテストに、移動・別パスへのコピー・別プロセス・同期の不整合を追加。

Dropbox等の実サービスとの同期や複数端末の変更統合は実装しません。一度に一台で使用します。

# 開発版 0.2.0 の変更

公開名の提案はSeqAtelier。これは元の0.1.0を基にした、配布・接続検証用の未公開候補版です。

- 配布名・CLI・Python importを `seqatelier`、環境変数を `SEQATELIER_*` に統一。
- `host` コマンドでWebとMCPを一つのサーバーへ統合。認証設定なしでは起動を拒否。
- Auth0のGitHubログイン用Web画面と、OAuthの署名・issuer・audience・期限・scope・本人ID確認。
- Renderの有料1サービス＋1 GB永続ディスクのBlueprint、Docker用CI検証を追加。
- Windowsで106件成功、1件は未インストールのprimer3によるskip。OAuthは合成鍵で検証。

- CLIを追加。初期化、診断、GenBank入出力、検索、設計、設計保存、発注CSV、履歴・復元・バックアップ。
- ファイルパス依存のWebサーバーをパッケージへ移し、Web画面をwheelに同梱。
- workspaceをソースコードから分離。SQLiteにメタデータを、内容ハッシュ付きGenBankに各版を保存。
- 下書きの再起動後復旧、版チェックによる競合検出、過去の版からの復元。
- 公式MCP Python SDKを使用し、stdioとStreamable HTTPを実装。
- MCPは読み取り専用を既定とし、明示的に新規取り込み・設計保存を有効化可能。
- WebのGenBank取り込み、書き出し、履歴と接続トークン入力を追加。
- 設計プレビューと保存を分離し、保存結果へ入力配列の版と計算パラメーターを記録。
- 逆鎖CDSとcodon_startを反映する残基指定、CDS外の残基番号の拒否、曖昧な結合部位の拒否。
- 発注情報の精製グレードとnotesの変換を修正。
- 人工配列によるデモ、接続スキル、Docker/Compose設定、OS別CI、wheel単体のインストール検証を追加。

既存の配列・index.csv・発注データは配布物に含めず、元のプロジェクトも変更していません。

制約: 実Auth0ログイン・複数利用者の権限分離・Dots実接続・クラウド配置・外部公開は未完了。
既存データの一括移行、汎用アラインメント、primer3の新規機能、複数断片の組立て検証はこの版では追加していません。
